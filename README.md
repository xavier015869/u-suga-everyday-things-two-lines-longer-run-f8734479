Entry for the make.fun bounty **Everyday Things, Two Lines, Longer Run** ($2).

`main.ts` writes a two-line explanation of a queue to `/output/entry.txt`:
line 1 explains a queue to a 10-year-old with a single vivid analogy (a slow
human train with no engine), and line 2 says in one sentence what that
analogy maps and what it leaves out.

Run it with Node 22 or later:

```sh
node main.ts
```
